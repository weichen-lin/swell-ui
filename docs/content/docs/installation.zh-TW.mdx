title: 安裝
description: 把 swell-ui 加進 React 19 + Tailwind CSS v4 的專案。
---

Peer dependencies：`react` 與 `react-dom` 19、`tailwindcss` 4.3+。不需要安裝 icon 套件：內建 icon 都是內嵌 SVG，而且每一個都能替換（見[圖示](/icons)）。

```sh
pnpm add @weichenlin/swell-ui
```

在匯入 Tailwind 的 CSS 檔裡加上：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

`styles.css` 包含 token（`theme.css`），以及一條 `@source`，讓 Tailwind 掃描打包好的元件。Tailwind 預設會略過 `node_modules`，有了它，元件用到的 class 才會被產生。

接著就能使用元件。`toast()` 需要在應用程式的根部附近渲染一個 `<Toaster />`：

```tsx
import { Button, toast, Toaster } from '@weichenlin/swell-ui'

export function App() {
  return (
    <>
      <Button onClick={() => toast.success('Saved')}>Save</Button>
      <Toaster />
    </>
  )
}
```

## Next.js App Router

套件入口第一行就是 `'use client'`，所以 Server Component 可以直接 import 並渲染元件，不必自己另包一層檔案：

```tsx
// app/page.tsx：Server Component
import { Button } from '@weichenlin/swell-ui'

export default function Page() {
  return <Button>Deploy</Button>
}
```

函式無法從 Server Component 傳給 Client Component，所以任何函式 prop 都必須從 Client Component 傳入：`onClick` 這類事件處理器、`Table` 的 `getRowId` 與欄位的 `cell`、`Slider` 的 `formatValue` 等等。非元件的匯出（`cn`、`toast`、`useTheme`）也經由同一個 client 入口匯出，只能在 Client Component 裡呼叫。
