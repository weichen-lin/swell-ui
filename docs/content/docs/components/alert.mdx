## Installation

```tsx
import { Alert } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Alert } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Alert tone="info" title="Next sync at 11:00">
      The order count refreshes after the sync completes.
    </Alert>
  )
}
```

## Accessibility

- An alert has no role and is not a live region: it does not announce itself. For updates that need announcing, put the message in a live region.
- The icon is `aria-hidden`. Tone never carries meaning alone: write it in the title or text.
- The dismiss button is named `Dismiss alert`; pass `dismissLabel` to localize it.
- The caller controls visibility: `onDismiss` only reports the click.
- Long words wrap, so a narrow container does not overflow.
- In forced colors mode the border is drawn in `CanvasText`.
