## Installation

```tsx
import { Drawer, DrawerBody, DrawerClose, DrawerFooter, DrawerHeader } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

`Drawer` is controlled through `open` and `onOpenChange`. It needs an accessible name: a `DrawerHeader` title, `aria-label` or `aria-labelledby`.

```tsx
import { Button, Drawer, DrawerBody, DrawerHeader } from '@weichenlin/swell-ui'
import { useState } from 'react'

export function Example() {
  const [open, setOpen] = useState(false)
  return (
    <>
      <Button onClick={() => setOpen(true)}>Open</Button>
      <Drawer open={open} onOpenChange={setOpen}>
        <DrawerHeader title="Filters" />
        <DrawerBody>Content</DrawerBody>
      </Drawer>
    </>
  )
}
```

## Accessibility

- Built on the native `<dialog>` with `showModal()`: the page behind is inert, focus stays inside and goes back to the trigger on close.
- The drawer needs a name: a `DrawerHeader` title, `aria-label` or `aria-labelledby`. A missing name logs a warning in development.
- The title names the drawer and the description describes it, only while rendered.
- `DrawerClose` requires `aria-label`; the types reject it without one. Both close buttons show only an icon and have no tooltip, since it would repeat the name.
- A backdrop click closes only when the press and the release both land on the backdrop.
- Page scroll is locked until the exit has finished.
- With reduced motion, the panel fades instead of sliding.
- In forced colors mode the panel border is drawn in `CanvasText`.
- On narrow screens the panel is at most the viewport width minus 56px, so the backdrop stays reachable.
- `DrawerHeader`, `DrawerBody`, `DrawerFooter` and `DrawerClose` throw outside a `Drawer`, and inside a `Dialog`.
