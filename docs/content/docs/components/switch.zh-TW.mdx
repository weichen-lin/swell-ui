## 安裝

```tsx
import { Switch } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Switch } from '@weichenlin/swell-ui'

export function Example() {
  return <Switch name="notifications" label="Notifications" />
}
```

每個開關都需要可見的 `label`；若周圍的內容已經說明了它，也可以只給 `aria-label`。

## 無障礙

- 帶 `role="switch"` 的原生 `<input type="checkbox">`，所以表單、`required`、重設與點擊標籤都維持原生行為。
- 可見標籤是開關的名稱；`description` 與錯誤文字不會混進名稱，而是用 `aria-describedby` 連結。
- `loading` 時會設定 `aria-busy`，並吞掉點擊與 Space，而不是用 `disabled`，所以鍵盤焦點不會跑掉。
- 轉圈圖示是 `aria-hidden`，不會朗讀儲存狀態，請在你自己的介面顯示結果。
- 整列高度至少 24px；在觸控螢幕上，點擊範圍擴大到 44px，版面不變。
- 強制色彩模式下，軌道與滑塊使用 `Canvas`、`CanvasText` 與 `Highlight`，停用則用 `GrayText`。
