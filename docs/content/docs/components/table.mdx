## Installation

```tsx
import { Table, type TableColumn } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

`Table` is controlled UI: search, sorting, selection and pagination only render controls and report changes. You supply the already filtered, sorted and paged `data`.

```tsx
import { Table, type TableColumn } from '@weichenlin/swell-ui'

type Invoice = { id: string; customer: string; amount: number }

const columns: TableColumn<Invoice>[] = [
  { id: 'id', header: 'Invoice', cell: (row) => row.id, rowHeader: true },
  { id: 'customer', header: 'Customer', cell: (row) => row.customer },
  { id: 'amount', header: 'Amount', cell: (row) => `$${row.amount}`, numeric: true },
]

export function Example({ invoices }: { invoices: Invoice[] }) {
  return <Table data={invoices} columns={columns} getRowId={(row) => row.id} title="Invoices" />
}
```

## Accessibility

- Header cells are `scope="col"`; `rowHeader` columns render `<th scope="row">`.
- Sorted headers expose `aria-sort`, and sort controls are real buttons inside the header.
- The table is named by `title`, or by your `aria-label` or `aria-labelledby`. The scroll region is a labelled `section` (`Table` by default) with `tabindex="0"`, so keyboard users can scroll wide tables.
- Row checkboxes are named `Select row <id>`; the select-all checkbox is named `Select all rows on this page`.
- The selected count and the pagination range are `<output>` elements, which are announced as they change.
- Page buttons use `aria-disabled`, not native `disabled`, so focus is not lost at either end.
- Every built-in string can be replaced through `labels`, for localization.
- The chevrons in pagination flip in right-to-left layouts.
