## 安裝

```tsx
import {
  Dialog,
  DialogBody,
  DialogFooter,
  DialogHeader,
  type DialogCloseReason,
} from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

`Dialog` 是受控元件：由 `open` 決定開關，所有關閉請求（Esc、背景遮罩、關閉按鈕）都會經過 `onOpenChange`。

```tsx
import { Button, Dialog, DialogBody, DialogFooter, DialogHeader } from '@weichenlin/swell-ui'
import { useState } from 'react'

export function Example() {
  const [open, setOpen] = useState(false)
  return (
    <>
      <Button onClick={() => setOpen(true)}>Open</Button>
      <Dialog open={open} onOpenChange={setOpen}>
        <DialogHeader title="Sync app" />
        <DialogBody>Content</DialogBody>
        <DialogFooter>
          <Button onClick={() => setOpen(false)}>Done</Button>
        </DialogFooter>
      </Dialog>
    </>
  )
}
```

## 無障礙

- 以原生 `<dialog>` 搭配 `showModal()` 實作：背景頁面變成 inert，焦點留在對話框內，關閉後回到原本的位置。
- `DialogHeader` 的標題作為對話框名稱，描述作為對話框描述。沒有使用時，請傳 `aria-label` 或 `aria-labelledby`。
- 設定 `alert` 時角色為 `alertdialog`，且沒有關閉按鈕，回應動作放在頁尾。請在破壞性最小的按鈕上設定 `autoFocus`；對話框會在 React 套用 `autoFocus` 之前先開啟，所以焦點能落在該按鈕。沒有 `autoFocus` 時，焦點落在第一個可聚焦元素。
- 背景遮罩的點擊必須在遮罩上按下並放開才算關閉，所以選取文字後在外面放開不會關閉對話框。
- 關閉按鈕的名稱是 `Close`，且不加 tooltip，因為會和名稱重複。
- 頁面捲動會鎖到退場結束，疊了多個 modal 時，鎖到最後一個關閉為止。
- 強制色彩模式下，面板邊框用 `CanvasText` 繪製。
- `DialogHeader`、`DialogBody`、`DialogFooter` 在 `Dialog` 之外，或放進 `Drawer` 裡，都會丟出錯誤。
