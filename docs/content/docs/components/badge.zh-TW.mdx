## 安裝

```tsx
import { Badge } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Badge } from '@weichenlin/swell-ui'

export function Example() {
  return <Badge tone="success">Healthy</Badge>
}
```

## 鍵盤操作

徽章不可聚焦，也不接收按鍵。需要動作時請用 `Button` 或連結。

## 無障礙

- 徽章是沒有 role、沒有 `tabindex` 的 `<span>`；型別刻意不允許 `onClick`。
- 用 `context` 讓螢幕閱讀器念出狀態所指的對象：文字內容會變成「Health: Unknown」。
- `icon` 與進行中的圓環放在 `aria-hidden` 的容器裡，無障礙文字就是標籤本身。
- 不只靠顏色傳達：每種樣式都有 1px 邊框，強制色彩模式下以 `CanvasText` 繪製。
- 開啟 `prefers-reduced-motion: reduce` 時，旋轉圓環改為靜態圓環。
