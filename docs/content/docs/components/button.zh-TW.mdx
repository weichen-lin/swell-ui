## 安裝

```tsx
import { Button } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Button } from '@weichenlin/swell-ui'

export function Example() {
  return <Button onClick={() => save()}>Save</Button>
}
```

## 無障礙

- 純圖示按鈕必須有 `aria-label`；型別會擋下沒有 `aria-label` 的 `icon`。顯示名稱的 tooltip 不會設成描述，因為內容和名稱重複。
- 停用與載入中用 `aria-disabled`，不用原生 `disabled`，鍵盤與螢幕閱讀器使用者不會失去目前位置。
- 載入中會設定 `aria-busy`。`loadingText` 透過按鈕旁的 polite live region 朗讀，不會混進按鈕名稱。
- `iconLeft`、`iconRight` 與轉圈圖示都是 `aria-hidden`；按鈕名稱來自文字。
- 沒設定時 `type` 是 `button`：表單的送出按鈕要傳 `type="submit"`。
- 在觸控螢幕上，點擊範圍至少 44×44px，視覺大小不變。
- 強制色彩模式下，邊框用 `ButtonText` 繪製，按下用 `Highlight`，停用用 `GrayText`。
- 開啟 `prefers-reduced-motion: reduce` 時不播放漣漪效果。
