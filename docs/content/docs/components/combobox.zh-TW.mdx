## 安裝

```tsx
import { Combobox } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Combobox } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Combobox
      label="Project"
      placeholder="Search projects"
      options={[
        { value: 'payment-api', label: 'Payment API' },
        { value: 'analytics', label: 'Analytics' },
      ]}
    />
  )
}
```

選取依據的是選項的 `value`（穩定的 ID），而不是輸入的文字。受控用 `value` 搭配 `onValueChange`，非受控用 `defaultValue`。設定 `name` 時，表單送出的是 `value`。

## 無障礙

- 遵循帶清單的 combobox 模式：輸入框有 `role="combobox"`、`aria-autocomplete="list"`、`aria-expanded` 與 `aria-controls`。DOM 焦點不會離開輸入框，選項透過 `aria-activedescendant` 指定。
- listbox 的名稱來自 `label` 或 `aria-label`；群組的名稱是它的 `label`。選項使用 `aria-selected` 與 `aria-disabled`，選項的 `description` 是它的無障礙描述。
- 結果數量會以 polite 方式朗讀，`loadingText` 與字串型的 `searchError` 也是；用 `getResultsText` 在地化數量文字。「沒有結果」是狀態訊息，不是選項。
- 清除與箭頭按鈕都有無障礙名稱（`clearLabel`、`openLabel`、`closeLabel`）；箭頭按鈕不在 Tab 順序中，因為輸入框本身就能開啟清單。
- `required` 檢查的是有沒有選取，不是有沒有輸入文字。訊息是 `requiredText`；當 `value` 對應不到任何選項時是 `unresolvedText`。選取的 ID 可能不在目前結果中時，請提供 `selectedOption`。
- 選項圖示、`start` 與打勾圖示都是 `aria-hidden`。
- 使用輸入法（IME）輸入是安全的：用來結束組字的 Enter 不會被攔截，組好的文字也會被搜尋。
- 在觸控螢幕上，選項與按鈕至少 44px。強制色彩模式下，作用中的選項以 `Highlight` 描邊。
- 開啟 `prefers-reduced-motion: reduce` 時，面板不播放淡入。
