## 安裝

```tsx
import { Textarea } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Textarea } from '@weichenlin/swell-ui'

export function Example() {
  return <Textarea label="Message" name="message" />
}
```

每個 textarea 都需要可見的 `label`；若周圍的內容已經說明了欄位，也可以只給 `aria-label`。

## 範例

### 字數統計

`showCount` 以 UTF-16 長度計算，和原生 `maxLength` 一致，超過上限時會變紅。受控的值不會被截斷。

高度會在 `minRows` 與 `maxRows` 之間跟著內容變化，超過後出現捲軸。

## API

只列元件自己的 props；其他 `<textarea>` 屬性都會直接傳給元素，`children` 除外，`rows` 在這裡是元件的 prop。`className` 會套在最外層欄位。

<AutoTypeTable

  name="TextareaProps"

/>

- `label` 與 `aria-label` 二擇一；`floating` 需要可見的 `label`。
- `rows` 與 `resize` 用於固定高度；`minRows` 與 `maxRows` 只能搭配 `autoResize`。混用會有型別錯誤。
- `rows`、`minRows`、`maxRows` 必須是正整數，且 `maxRows` 不能小於 `minRows`，否則 Textarea 會丟出 `RangeError`。

## 無障礙

- `label` 會渲染成真正的 `<label>` 並連結到 textarea。浮動標籤缺口裡重複的標籤文字是 `aria-hidden`，不會混進無障礙名稱。
- 輔助與錯誤文字、字數都用 `aria-describedby` 連結，你自己傳入的 `aria-describedby` 排在最前面。錯誤另外會設定 `aria-invalid`。
- 字數不是 live region，所以不會每按一個鍵就朗讀。
- 字數以 UTF-16 長度計算，和原生 `maxLength` 一致，所以一個 emoji 算 2。
- `mono` 會關閉拼字檢查、自動修正與自動大寫。
- 原生表單重設會一併更新字數與自動調整後的高度。
- 在觸控螢幕上，文字為 16px。
