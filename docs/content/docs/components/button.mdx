## Installation

```tsx
import { Button } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Button } from '@weichenlin/swell-ui'

export function Example() {
  return <Button onClick={() => save()}>Save</Button>
}
```

## Accessibility

- Icon-only buttons must have `aria-label`; the types reject an `icon` without one. The label tooltip is not wired as a description, since it repeats the name.
- Disabled and loading use `aria-disabled`, not native `disabled`, so keyboard and screen reader users keep their place.
- Loading sets `aria-busy`. `loadingText` is announced through a polite live region next to the button, outside its name.
- `iconLeft`, `iconRight` and the spinner are `aria-hidden`; the label is the name.
- `type` is `button` unless set: pass `type="submit"` for a form's submit button.
- On touch screens the hit area grows to at least 44×44px without changing the visual size.
- In forced colors mode the border is drawn in `ButtonText`, pressed uses `Highlight`, disabled `GrayText`.
- The ripple is skipped under `prefers-reduced-motion: reduce`.
