## Installation

```tsx
import {
  Dialog,
  DialogBody,
  DialogFooter,
  DialogHeader,
  type DialogCloseReason,
} from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

`Dialog` is controlled: `open` drives it, and every close request (Esc, backdrop, close button) goes through `onOpenChange`.

```tsx
import { Button, Dialog, DialogBody, DialogFooter, DialogHeader } from '@weichenlin/swell-ui'
import { useState } from 'react'

export function Example() {
  const [open, setOpen] = useState(false)
  return (
    <>
      <Button onClick={() => setOpen(true)}>Open</Button>
      <Dialog open={open} onOpenChange={setOpen}>
        <DialogHeader title="Sync app" />
        <DialogBody>Content</DialogBody>
        <DialogFooter>
          <Button onClick={() => setOpen(false)}>Done</Button>
        </DialogFooter>
      </Dialog>
    </>
  )
}
```

Own props only; every other `<dialog>` attribute passes through to the element.

### DialogBody and DialogFooter

Plain `div` wrappers. `DialogBody` scrolls when the content is taller than the space between header and footer. `DialogFooter` right-aligns actions: Cancel first, the primary action last.

## Accessibility

- Built on the native `<dialog>` with `showModal()`: the page behind is inert, focus stays inside and goes back to where it was on close.
- `DialogHeader` names the dialog with its title and describes it with its description. Without one, pass `aria-label` or `aria-labelledby`.
- With `alert`, the role is `alertdialog` and there is no close button, so the answer is in the footer. Put `autoFocus` on the least destructive button; the dialog opens before React applies it, so it lands. Without `autoFocus`, the first focusable element gets focus.
- A backdrop click closes only when the press and the release both land on the backdrop, so selecting text and releasing outside does not dismiss.
- The close button is named `Close` and has no tooltip, since it would repeat the name.
- Page scroll is locked until the exit has finished, and stays locked until the last stacked modal closes.
- In forced colors mode the panel border is drawn in `CanvasText`.
- `DialogHeader`, `DialogBody` and `DialogFooter` throw outside a `Dialog`, and inside a `Drawer`.
