## Installation

```tsx
import { Checkbox, CheckboxGroup } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import {
  Checkbox,
  CheckboxGroup,
  CheckboxGroupItems,
  CheckboxGroupLabel,
} from '@weichenlin/swell-ui'

export function Example() {
  return (
    <CheckboxGroup>
      <CheckboxGroupLabel>Options</CheckboxGroupLabel>
      <CheckboxGroupItems>
        <Checkbox name="options" value="a" label="Option A" />
        <Checkbox name="options" value="b" label="Option B" />
      </CheckboxGroupItems>
    </CheckboxGroup>
  )
}
```

Every checkbox needs a visible `label`, or an `aria-label` when the surrounding context already names it, as in a table row.

## API

### Checkbox

Own props only; every other `<input type="checkbox">` attribute passes through to the element, except `type` and `size`. `className` goes to the row.

`label` and `aria-label` are alternatives: pass a visible `label`, or only `aria-label`.

### CheckboxGroup

Own props only; every other `<fieldset>` attribute passes through to the element.

<AutoTypeTable
  path="src/components/checkbox/checkbox-group.tsx"
  name="CheckboxGroupProps"
  keep={['disabled']}
/>

`CheckboxGroup` holds no value. Each checkbox keeps its own `name` and `checked`, so native form submission and `FormData` work as usual.

#### Anatomy

The group owns the wiring; you place each part, or leave it out.

```tsx
<CheckboxGroup>
  <CheckboxGroupLabel>Notify me by</CheckboxGroupLabel>
  <CheckboxGroupDescription>Pick at least one.</CheckboxGroupDescription>
  <CheckboxGroupItems>
    <Checkbox name="channels" value="email" label="Email" />
    <Checkbox name="channels" value="sms" label="SMS" />
  </CheckboxGroupItems>
  {error && <CheckboxGroupError>{error}</CheckboxGroupError>}
</CheckboxGroup>
```

| Part                       | Role                                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `CheckboxGroupLabel`       | Names the group.                                                                                                     |
| `CheckboxGroupDescription` | Muted hint, linked with `aria-describedby`.                                                                          |
| `CheckboxGroupItems`       | Default layout for the rows, following `orientation`. Any element works instead.                                     |
| `CheckboxGroupError`       | Group message, linked with `aria-describedby`. Takes `icon`; `false` or `null` hides it. Render it only when needed. |

To hide the label visually and keep it for assistive technology, add `sr-only`:

```tsx
<CheckboxGroup>
  <CheckboxGroupLabel className="sr-only">Notify me by</CheckboxGroupLabel>
  <CheckboxGroupItems>{/* checkboxes */}</CheckboxGroupItems>
</CheckboxGroup>
```

Without a label part, name the group with `aria-label` or `aria-labelledby`.

## Accessibility

- A native `<input type="checkbox">`, so forms, `required`, reset and label clicks stay native.
- The visible label names the checkbox; `description` and the error text stay out of the name and are linked with `aria-describedby`.
- `indeterminate` is announced as mixed. The browser clears the DOM property on click, so Checkbox re-applies it whenever `checked` changes.
- `CheckboxGroup` is a `<fieldset>` named by `CheckboxGroupLabel` through `aria-labelledby`, or by `aria-label` when there is no label part. It does not set `aria-invalid`, because ARIA 1.2 does not support it on the group role; `CheckboxGroupDescription` and `CheckboxGroupError` are linked with `aria-describedby` while they are rendered.
- Native `required` cannot express "at least one", so validate in your submit handler and render a `CheckboxGroupError`.
- The check, the dash and the error icon are `aria-hidden`.
- The row is at least 24px tall; on touch screens the hit area grows to 44px without changing the layout.
- In forced colors mode the box uses `Canvas`, `Highlight` and `CanvasText`, and disabled uses `GrayText`.
