## 安裝

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import {
  Button,
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from '@weichenlin/swell-ui'

export function Example() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button intent="secondary">Actions</Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem onSelect={() => console.log('edit')}>Edit</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

在 `DropdownMenu` 裡放一個 `DropdownMenuTrigger` 和一個 `DropdownMenuContent`。用 `asChild` 可以把觸發按鈕或項目換成你自己的元素，例如 `Button` 或 router 的連結。選單只有單層：沒有子選單，也沒有核取方塊或單選項目。

## 無障礙

- 觸發按鈕有 `aria-haspopup="menu"` 與 `aria-expanded`；面板是 `role="menu"`，名稱來自觸發按鈕（除非你傳了 `aria-label`），項目是 `role="menuitem"`。
- 開啟時焦點會移進選單，並用方向鍵一次移動一個項目：項目不在 Tab 順序中。
- 按 Escape 或選取項目後，焦點會回到觸發按鈕；但點擊選單外、按 Tab，或選取時自己把焦點移到別處，則不會。
- 停用的項目與觸發按鈕保有焦點並使用 `aria-disabled`；停用的 `asChild` 項目裡的連結無法被點開。
- `iconLeft` 是 `aria-hidden`。Typeahead 比對的是項目的文字；文字不同時請設定 `textValue`。
- `DropdownMenuLabel` 並未和群組串起來：請用 `aria-label` 為群組命名。
- 面板是原生的 popover，位於最上層，不會被捲動容器裁掉，在對話框內也一樣。點擊選單外或焦點移出時會關閉。
- 在觸控螢幕上，項目高度至少 40px。開啟 `prefers-reduced-motion: reduce` 時不播放淡入。
