## Installation

```tsx
import { CopyInput, Input, PasswordInput, SearchInput } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Input } from '@weichenlin/swell-ui'

export function Example() {
  return <Input label="Project name" placeholder="payments-api" />
}
```

Every input needs a visible `label`, or an `aria-label` when the surrounding context already names the field. `Input` supports `text`, `email`, `url` and `tel`.

## API

### Input

Own props only; every other `<input>` attribute passes through to the element, except `size`. `className` goes to the outer wrapper. There is no `number` type: use `inputMode="numeric"` instead.

/>

`label` and `aria-label` are alternatives: pass a visible `label`, or only `aria-label`. `floating` needs a visible `label`.

### SearchInput

Takes the `Input` props except `type`, `label`, `floating` and `start`.

### PasswordInput

Takes the `Input` props except `type`. A toggle button shows or hides the password. `autoComplete` defaults to `current-password`; use `new-password` on sign-up and reset forms.

### CopyInput

Takes the `Input` props except `type`, `defaultValue`, `readOnly` and `onChange`. Pass `label`, or `aria-label` alone when the context names the value.

## Accessibility

- `label` renders a real `<label>` linked to the input. With `aria-label` only, the field has no visible label; `floating` needs a visible one.
- Helper and error text are linked with `aria-describedby`; the error also sets `aria-invalid`. The error icon is `aria-hidden`.
- In the floating notch, the repeated label text is `aria-hidden` and never joins the accessible name.
- `start` and `end` icons are `aria-hidden`; plain text stays readable.
- `validating` announces `validatingText` in a separate polite live region, so the name and description stay unchanged.
- `PasswordInput` keeps a stable "Show password" button name and reflects the state with `aria-pressed`.
- `CopyInput` selects its text on focus and announces "Copied" or "Copy failed" politely. Localize the button name and both announcements with `copyLabel`, `copiedLabel` and `copyFailedLabel`.
- Buttons inside the field do not take focus from the input on pointer press.
- On touch screens the field hit area grows to at least 44px high and the text is 16px.
- In forced colors mode the floating outline shows only on focus, and a disabled border uses `GrayText`.
