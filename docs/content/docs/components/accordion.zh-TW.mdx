## 安裝

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Accordion defaultValue="project">
      <AccordionItem value="project">
        <AccordionTrigger>Project</AccordionTrigger>
        <AccordionContent>Project settings</AccordionContent>
      </AccordionItem>
      <AccordionItem value="members">
        <AccordionTrigger>Members</AccordionTrigger>
        <AccordionContent>Member settings</AccordionContent>
      </AccordionItem>
    </Accordion>
  )
}
```

項目的 `value` 必須唯一且不可為空。每個 trigger 都會自己渲染一個標題，所以它的內容不能包含可互動的元素。單選模式的值是 `string | null`；`type="multiple"` 時是 `readonly string[]`。受控用 `value` 搭配 `onValueChange`，非受控用 `defaultValue`。掛載後不能更改 type：要切換請給元件新的 `key`。

### 受控

`collapsible={false}` 會讓一個項目保持展開：展開中的 trigger 仍可聚焦，但不會收合。

<ComponentPreview name="accordion-controlled" />

### 停用項目

在項目上設定 `disabled` 只會停用它的 trigger。設在 `Accordion` 上則會停用所有 trigger，且不改變目前的值。

## 無障礙

- 每個 trigger 都是原生 `<button>`，放在 `headingLevel` 指定層級的標題裡（預設 3）：請選擇符合你頁面大綱的層級。
- trigger 有 `aria-expanded` 與 `aria-controls`。它的名稱只有標題；`description` 以描述的方式朗讀。
- 內容預設不是地標。內容複雜時，設定 `region` 就會以 trigger 命名它，請節制使用。
- 已收合的內容會立即設為 `inert`，並對輔助技術隱藏，焦點不會落入其中。收合時如果焦點在內容裡，會移到該項目的 trigger，再不行就移到相鄰的可用 trigger。
- `disabled` 只停用 trigger：內容裡的欄位仍可使用，`keepMounted`（預設）也會在項目收合時保留它們的值與表單資料。
- 方向鍵、Home 與 End 會忽略搭配 Ctrl、Alt、Meta 或 Shift 的組合，巢狀的 accordion 處理自己的按鍵與選取。
- 箭頭是 `aria-hidden`。強制色彩模式下，停用的 trigger 用 `GrayText`。
- 高度動畫展開 200ms、收合 160ms；開啟 `prefers-reduced-motion: reduce` 時會立即切換。
