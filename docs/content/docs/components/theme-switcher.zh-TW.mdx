## 安裝

```tsx
import { ThemeSwitcher, useTheme } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

`ThemeSwitcher` 是受控的圖示按鈕。點一下就會切換目前看到的主題，即使目前的值是 `'system'` 也一樣。搭配 `useTheme` hook 使用：它會保存選擇，並在根元素設定 `data-theme`（`'system'` 會清除該屬性，交由 `prefers-color-scheme` 決定）。

```tsx
import { ThemeSwitcher, useTheme } from '@weichenlin/swell-ui'

export function Header() {
  const { theme, setTheme } = useTheme()
  return <ThemeSwitcher value={theme} onChange={setTheme} />
}
```

上方的範例改用單純的 state，所以不會改變本站的主題。

### useTheme(options?)

回傳 `{ theme, setTheme }`。保存的值只在掛載時讀取一次；不是 `'light'` 或 `'dark'` 的值都視為 `'system'`。如果 `localStorage` 拋出錯誤，主題在當次瀏覽中仍可運作。

## 無障礙

- 按鈕的名稱描述它的動作（「Switch to dark theme」），並隨目前主題更新。要替換名稱（例如在地化）時傳入 `aria-label`。
- 同樣的文字也會設為 `title`；tooltip 已關閉，所以名稱不會重複顯示。
- 圖示是裝飾性的，並設為 `aria-hidden`。
- 按鈕大小為 44×44px（`size-11`）。
- 停用時用 `aria-disabled`，按鈕保留在 Tab 順序中。

## 主題

`themes/flat.css` 只影響按鈕的圓角（`--radius-control`），並讓滑鼠移入的底色以完整強度套用（`--hover-strength: 1`）。`data-theme` 與色彩 token 如何切換，請見[暗色模式](/dark-mode)。
