## Installation

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import {
  Button,
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from '@weichenlin/swell-ui'

export function Example() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button intent="secondary">Actions</Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem onSelect={() => console.log('edit')}>Edit</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

Put a `DropdownMenuTrigger` and a `DropdownMenuContent` inside `DropdownMenu`. Use `asChild` to render the trigger or an item as your own element, such as a `Button` or a router link. The menu is a single level: there are no submenus, checkbox or radio items.

## Accessibility

- The trigger has `aria-haspopup="menu"` and `aria-expanded`; the panel is `role="menu"`, named by the trigger unless you pass `aria-label`, and items are `role="menuitem"`.
- Focus moves into the menu on open and between items by arrow keys, one item at a time: items are not in the Tab order.
- Focus returns to the trigger after Escape or choosing an item, but not after clicking outside, Tab, or when the selection moved focus elsewhere itself.
- Disabled items and triggers keep focus and use `aria-disabled`; a link inside a disabled `asChild` item cannot be followed.
- `iconLeft` is `aria-hidden`. Typeahead uses the item's text; set `textValue` when it differs.
- `DropdownMenuLabel` is not wired to its group: name a group with `aria-label`.
- The panel is a native popover, so it sits in the top layer above scroll containers, including inside a dialog. It closes on a click outside or focus moving out.
- On touch screens items are at least 40px tall. The fade-in is skipped under `prefers-reduced-motion: reduce`.
