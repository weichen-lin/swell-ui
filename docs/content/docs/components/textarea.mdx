## Installation

```tsx
import { Textarea } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Textarea } from '@weichenlin/swell-ui'

export function Example() {
  return <Textarea label="Message" name="message" />
}
```

Every textarea needs a visible `label`, or an `aria-label` when the surrounding context already names the field.

## API

Own props only; every other `<textarea>` attribute passes through to the element, except `children` and `rows` (a prop here). `className` goes to the outer field.

<AutoTypeTable
  path="src/components/textarea/textarea.tsx"
  name="TextareaProps"
  keep={['className', 'disabled']}
/>

- `label` and `aria-label` are alternatives; `floating` needs a visible `label`.
- `rows` and `resize` are for a fixed height; `minRows` and `maxRows` only work with `autoResize`. Mixing them is a type error.
- `rows`, `minRows` and `maxRows` must be positive integers, and `maxRows` at least `minRows`, or Textarea throws a `RangeError`.

## Accessibility

- `label` renders a real `<label>` linked to the textarea. In the floating notch, the repeated label text is `aria-hidden` and never joins the accessible name.
- Helper and error text are linked with `aria-describedby`, as is the count; your own `aria-describedby` comes first. The error also sets `aria-invalid`.
- The count is not a live region, so it is not announced on every keystroke.
- The count uses UTF-16 length, as native `maxLength` does, so an emoji counts as 2.
- `mono` turns off spellcheck, autocorrect and autocapitalize.
- A native form reset updates the count and the auto-resized height.
- On touch screens the text is 16px.
