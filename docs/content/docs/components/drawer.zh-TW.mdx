## 安裝

```tsx
import { Drawer, DrawerBody, DrawerClose, DrawerFooter, DrawerHeader } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

`Drawer` 透過 `open` 與 `onOpenChange` 控制。它需要無障礙名稱：`DrawerHeader` 的標題、`aria-label` 或 `aria-labelledby`。

```tsx
import { Button, Drawer, DrawerBody, DrawerHeader } from '@weichenlin/swell-ui'
import { useState } from 'react'

export function Example() {
  const [open, setOpen] = useState(false)
  return (
    <>
      <Button onClick={() => setOpen(true)}>Open</Button>
      <Drawer open={open} onOpenChange={setOpen}>
        <DrawerHeader title="Filters" />
        <DrawerBody>Content</DrawerBody>
      </Drawer>
    </>
  )
}
```

## 無障礙

- 以原生 `<dialog>` 搭配 `showModal()` 實作：背景頁面變成 inert，焦點留在抽屜內，關閉後回到觸發按鈕。
- 抽屜需要名稱：`DrawerHeader` 的標題、`aria-label` 或 `aria-labelledby`。缺少名稱時，開發模式會在 console 顯示警告。
- 標題作為抽屜名稱，描述作為抽屜描述，且只在它們有渲染時才設定。
- `DrawerClose` 必須有 `aria-label`；型別會擋下沒有它的用法。兩種關閉按鈕都只顯示圖示，且不加 tooltip，因為會和名稱重複。
- 背景遮罩的點擊必須在遮罩上按下並放開才算關閉。
- 頁面捲動會鎖到退場結束。
- 減少動態效果時，面板改為淡入淡出，不再滑動。
- 強制色彩模式下，面板邊框用 `CanvasText` 繪製。
- 窄螢幕上面板寬度最多是視窗寬度減 56px，遮罩仍然點得到。
- `DrawerHeader`、`DrawerBody`、`DrawerFooter`、`DrawerClose` 在 `Drawer` 之外，或放進 `Dialog` 裡，都會丟出錯誤。

## 主題

抽屜在 DOM 上仍位於預覽框內，所以上方的 Flat 切換對它同樣有效。`themes/flat.css` 會移除 `--shadow-dialog`，並加深 `--color-popover-border` 與 `--color-dialog-backdrop`。面板本來就是直角，所以圓角的調整不會影響它。
