## Installation

```tsx
import { Card, CardContent, CardHeader } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

Card has no padding of its own. `CardHeader` and `CardContent` add it, so lists and tables can run edge to edge.

```tsx
import { Card, CardContent, CardHeader } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Card as="section">
      <CardHeader title="Resources" description="Managed in shop-prod" />
      <CardContent>Any content goes here.</CardContent>
    </Card>
  )
}
```

## Keyboard

A card is not focusable and takes no key input. Controls you put inside, such as the `action` link, keep their own keys.

## Accessibility

- With `as="section"` or `as="article"`, the card is a region named by its `CardHeader` title.
- An explicit `aria-label` on the card takes precedence over the title.
- A `div` card is never labelled, and a card without a header sets no `aria-labelledby`.
- The title is a heading: `h2` by default, `h3` with `headingLevel={3}`. Pick the level that fits the page outline.
