## 安裝

```tsx
import { Tooltip } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Button, Tooltip } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Tooltip content="Pull the latest manifests from Git">
      <Button intent="secondary">Sync</Button>
    </Tooltip>
  )
}
```

[Button](/components/button) 已經用 tooltip 顯示自己的名稱（純圖示按鈕的 `aria-label`）與 `disabledReason`。其他觸發元素才需要直接使用 `Tooltip`。

## 無障礙

- tooltip 的角色是 `role="tooltip"`，觸發元素用 `aria-describedby` 指向它，內容會作為觸發元素的描述被朗讀。
- 當 tooltip 只是重複觸發元素的無障礙名稱（例如純圖示按鈕的標籤）時，把 `describe` 關掉。
- 鍵盤使用者也看得到 tooltip：它在 `:focus-visible` 時開啟，按 Esc 關閉。
- tooltip 本身不可聚焦，所以不要在裡面放按鈕或連結。
- 非互動式的觸發元素需要 `tabIndex={0}` 才聚焦得到。
- 事件綁在外層的 wrapper 上，所以 `aria-disabled` 的觸發元素也能開啟。
- 沒有 `content` 時，不會渲染任何東西，也不會加 `aria-describedby`。
- tooltip 以固定定位 portal 到 `<body>`，所以表格、抽屜等捲動容器不會裁掉它，且會跟著捲動與視窗大小調整位置。
- 在伺服器端只會渲染觸發元素；tooltip 在 hydration 之後才出現。
- 開啟 `prefers-reduced-motion: reduce` 時不播放轉場動畫。
