## 安裝

```tsx
import { CopyInput, Input, PasswordInput, SearchInput } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Input } from '@weichenlin/swell-ui'

export function Example() {
  return <Input label="Project name" placeholder="payments-api" />
}
```

每個輸入框都需要可見的 `label`；若周圍的內容已經說明了欄位，也可以只給 `aria-label`。`Input` 支援 `text`、`email`、`url` 與 `tel`。

## API

### Input

只列元件自己的 props；其他 `<input>` 屬性都會直接傳給元素，`size` 除外。`className` 會套在最外層容器。沒有 `number` 類型，請改用 `inputMode="numeric"`。

<AutoTypeTable
  path="src/components/input/input.tsx"
  name="InputProps"
  keep={['className', 'disabled']}
/>

`label` 與 `aria-label` 二擇一：給可見的 `label`，或只給 `aria-label`。`floating` 需要可見的 `label`。

### SearchInput

接受 `Input` 的 props，但不含 `type`、`label`、`floating` 與 `start`。

<AutoTypeTable
  path="src/components/input/search-input.tsx"
  name="SearchInputOwnProps"
  type={"Pick<SearchInputProps, 'aria-label' | 'onClear'>"}
/>

### PasswordInput

接受 `Input` 的 props，但不含 `type`。內建切換按鈕可顯示或隱藏密碼。`autoComplete` 預設為 `current-password`；註冊與重設密碼的表單請用 `new-password`。

### CopyInput

接受 `Input` 的 props，但不含 `type`、`defaultValue`、`readOnly` 與 `onChange`。傳 `label`；若上下文已說明這個值，也可以只傳 `aria-label`。

## 無障礙

- `label` 會渲染成真正的 `<label>` 並連結到 input。只給 `aria-label` 時，欄位沒有可見標籤；`floating` 需要可見標籤。
- 輔助與錯誤文字用 `aria-describedby` 連結；錯誤另外會設定 `aria-invalid`。錯誤圖示是 `aria-hidden`。
- 浮動標籤缺口裡重複的標籤文字是 `aria-hidden`，不會混進無障礙名稱。
- `start` 與 `end` 的圖示是 `aria-hidden`；純文字仍可被讀到。
- `validating` 會把 `validatingText` 放在獨立的 polite live region 朗讀，名稱與描述不受影響。
- `PasswordInput` 的按鈕名稱固定為「Show password」，狀態用 `aria-pressed` 表示。
- `CopyInput` 聚焦時選取全部文字，並以 polite 方式朗讀「Copied」或「Copy failed」。按鈕名稱和這兩句朗讀文字可用 `copyLabel`、`copiedLabel`、`copyFailedLabel` 換成中文。
- 在欄位內的按鈕上按下指標，不會把焦點從 input 搶走。
- 在觸控螢幕上，欄位的點擊範圍至少 44px 高，文字為 16px。
- 強制色彩模式下，浮動標籤的外框只在聚焦時顯示，停用的邊框用 `GrayText`。
