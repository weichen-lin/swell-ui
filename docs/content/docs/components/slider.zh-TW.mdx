## 安裝

```tsx
import { RangeSlider, Slider } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { RangeSlider, Slider } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <>
      <Slider label="Volume" defaultValue={40} />
      <RangeSlider
        label="Price range"
        thumbLabels={['Minimum price', 'Maximum price']}
        defaultValue={[200, 800]}
        min={0}
        max={1000}
        step={50}
      />
    </>
  )
}
```

每個滑桿都需要可見的 `label`；若周圍的內容已經說明了它，也可以只給 `aria-label`。

## API

### Slider

只列元件自己的 props；其他 `<div>` 屬性都會直接傳給根元素，`onChange`、`children` 與 `role` 除外。`className` 與 `ref` 指向根 `div`。

<AutoTypeTable path="src/components/slider/types.ts" name="SliderProps" keep={['className']} />

`label` 與 `aria-label` 二擇一：給可見的 `label`，或只給 `aria-label`。`value` 與 `defaultValue` 二擇一：只傳其中一個。省略 `defaultValue` 時為 `min`。

`SliderChangeDetails` 是 `{ thumbIndex: 0 | 1; reason: 'pointer' | 'keyboard' | 'input' | 'cancel' }`。`SliderCommitDetails` 相同，但沒有 `cancel` 這個 reason。

### RangeSlider

接受與 `Slider` 相同的 props，但下列 props 會取代 `Slider` 中對應的項目。省略 `defaultValue` 時為 `[min, max]`。

按住按鍵時，每一步都會透過 `onValueChange` 預覽；`onValueCommit` 在放開按鍵或焦點離開時執行一次，且若操作結束時回到起點就不會執行。同時按住 Ctrl、Alt、Meta 或 Shift 的按鍵會被忽略。滑塊會停在相鄰滑塊之前，不會交換或推開對方，所以 Home 與 End 也會遵守 `minStepsBetweenThumbs`。

## 無障礙

- 每個滑塊都是原生的 `<input type="range">`，放在 `role="group"` 裡，所以角色、數值與表單送出都由瀏覽器提供。
- 可見的 `label` 是群組與每個滑塊的名稱。`RangeSlider` 的每個滑塊，名稱是標籤加上對應的 `thumbLabels`；只有 `aria-label` 時，則是 `aria-label` 加上該滑塊的標籤。
- 朗讀的數值是 `formatValue(value)`，傳了 `getValueText` 則以它為準。畫面上的數值、上下界與標記都是 `aria-hidden`。
- 輔助與錯誤文字用 `aria-describedby` 連結；錯誤另外會設定 `aria-invalid`。
- 指標被取消、失去 capture 或視窗失焦時，數值會還原，透過 `onValueChange` 以 `cancel` 這個 reason 通知，且不會 commit。
- 不處理 Esc，所以它會傳給外層，例如對話框。
- 點擊範圍高 44px；滑塊本身 18px，周圍有 44px 的觸控目標。
- 原生表單重設會還原非受控的預設值；受控時是否重設由使用者端決定。
- 強制色彩模式下，軌道、範圍條與滑塊使用 `CanvasText`、`Highlight` 與 `ButtonText`，停用則用 `GrayText`。
- `min` 與 `max` 必須是有限數且 `min < max`；數值必須落在 step 格線上、順序正確並符合滑塊間距，否則滑桿會丟出錯誤。
