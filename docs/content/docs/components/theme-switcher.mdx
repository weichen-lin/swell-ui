## Installation

```tsx
import { ThemeSwitcher, useTheme } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

`ThemeSwitcher` is a controlled icon button. It toggles the visible theme in one click, including when the current value is `'system'`. Pair it with the `useTheme` hook, which persists the choice and sets `data-theme` on the root element (`'system'` clears it so `prefers-color-scheme` decides).

```tsx
import { ThemeSwitcher, useTheme } from '@weichenlin/swell-ui'

export function Header() {
  const { theme, setTheme } = useTheme()
  return <ThemeSwitcher value={theme} onChange={setTheme} />
}
```

The demo above uses plain state instead, so it does not change this site's theme.

## Accessibility

- The button's name describes the action ("Switch to dark theme") and updates with the current theme. Pass `aria-label` to replace it, for example to localize.
- The same text is set as `title`; the tooltip is turned off, so the name is not shown twice.
- The icon is decorative and `aria-hidden`.
- The button is 44×44px (`size-11`), which meets the touch target size.
- Disabled uses `aria-disabled`, so the button keeps its place in the tab order.
