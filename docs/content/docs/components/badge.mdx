## Installation

```tsx
import { Badge } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Badge } from '@weichenlin/swell-ui'

export function Example() {
  return <Badge tone="success">Healthy</Badge>
}
```

## Keyboard

A badge is not focusable and takes no key input. Use a `Button` or a link when it needs an action.

## Accessibility

- A badge is a plain `<span>` with no role and no `tabindex`; the types reject `onClick` on purpose.
- Use `context` so screen readers announce what the status refers to: it becomes "Health: Unknown" in the text content.
- `icon` and the busy spinner sit in an `aria-hidden` slot, so the label is the whole accessible text.
- Color is not the only signal: every variant keeps a 1px border, and in forced colors mode it is drawn in `CanvasText`.
- The spinner is replaced by a static ring under `prefers-reduced-motion: reduce`.

## Theming

`themes/flat.css` only makes `--radius-item` smaller (6px to 4px); badges use no shadows.
