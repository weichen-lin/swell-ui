## Installation

```tsx
import { Switch } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Switch } from '@weichenlin/swell-ui'

export function Example() {
  return <Switch name="notifications" label="Notifications" />
}
```

Every switch needs a visible `label`, or an `aria-label` when the surrounding context already names it.

## API

Own props only; every other `<input type="checkbox">` attribute passes through to the element, except `type`, `size`, `role` and `aria-checked`. `className` goes to the row.

## Accessibility

- A native `<input type="checkbox">` with `role="switch"`, so forms, `required`, reset and label clicks stay native.
- The visible label names the switch; `description` and the error text stay out of the name and are linked with `aria-describedby`.
- While `loading`, it sets `aria-busy` and swallows clicks and Space instead of using `disabled`, so keyboard focus stays put.
- The spinner is `aria-hidden`; it does not announce the saving state, so show the result in your own UI.
- The row is at least 24px tall; on touch screens the hit area grows to 44px without changing the layout.
- In forced colors mode the track and thumb use `Canvas`, `CanvasText` and `Highlight`, and disabled uses `GrayText`.
