## Installation

```tsx
import { Select } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Select } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Select
      label="Region"
      placeholder="Choose a region"
      options={[
        { value: 'us-east', label: 'US East' },
        { value: 'eu-west', label: 'EU West' },
      ]}
    />
  )
}
```

`Select` renders a real `<select>`, so native keyboard support, typeahead, forms, validation and autofill all work. Where the browser supports `appearance: base-select`, the picker is styled to match; elsewhere it stays native. It shares its frame with `Input`.

## Accessibility

- It is a native `<select>`: the role, value, typeahead and form participation come from the browser.
- A visible `label` is a real `<label>` for the select. With only `aria-label`, there is no label element; the types require one of the two, and `floating` needs a visible `label`.
- `helperText` and `error` are linked with `aria-describedby`; an error also sets `aria-invalid` and shows an icon that is `aria-hidden`.
- The empty "nothing chosen" option is hidden and disabled, so it is never offered in the list, and a `required` select fails validation until a real option is chosen.
- Option icons, `start` and the chevron are `aria-hidden`. Icons add no text, so the accessible name and typeahead use `label` only.
- `form.reset()` restores the initial option, and the trigger icon follows.
- The styled picker applies to fine pointers only; on touch the OS picker is kept, the text grows to 16px and the hit area to at least 44px.
- In forced colors mode, the disabled border is `GrayText` and focus is drawn as an outline.
- The picker fades in with a short transition that is skipped under `prefers-reduced-motion: reduce`.
