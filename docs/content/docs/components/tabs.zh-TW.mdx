## 安裝

```tsx
import { Tab, TabList, TabPanel, Tabs } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Tab, TabList, TabPanel, Tabs } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Tabs defaultValue="a" aria-label="Sections">
      <TabList>
        <Tab value="a">A</Tab>
        <Tab value="b">B</Tab>
      </TabList>
      <TabPanel value="a">First</TabPanel>
      <TabPanel value="b">Second</TabPanel>
    </Tabs>
  )
}
```

分頁列需要名稱：傳入 `aria-label` 或 `aria-labelledby`。用 `defaultValue`（非受控），或 `value` 搭配 `onValueChange`（受控）；兩者必須擇一。

## 無障礙

- `Tabs` 遵循 WAI-ARIA 的 tabs 模式：`role="tablist"`、`tab` 與 `tabpanel`，並以 `aria-controls` 與 `aria-labelledby` 相連。型別要求分頁列必須有名稱。
- 單一 `tabindex` 停駐點：Tab 進入被選取的分頁，方向鍵在列表內移動。面板本身也是停駐點，所以 Tab 會從列表直接進入內容。
- 選取分頁會載入資料時，請用 `activationMode="manual"`，避免方向鍵經過分頁就發出請求。
- 停用的分頁會被方向鍵跳過，點擊也沒有作用。巢狀的 `Tabs` 有自己的列表、按鍵與面板。
- 圖示是 `aria-hidden`。用來撐住寬度的粗體文字副本是隱藏的，所以名稱只會讀一次；徽章是名稱的一部分。
- `TabNav` 是 `<nav>` 加上由真正連結組成的列表：每個連結都能在新分頁開啟，`aria-current="page"` 標示你所在的位置。請替它命名，才能和其他導覽地標區分。
- 在觸控螢幕上，分頁至少 44px，列表也比較高。強制色彩模式下，指示器用 `Highlight`，停用的分頁用 `GrayText`。
