## 安裝

```tsx
import {
  Sidebar,
  SidebarBody,
  SidebarGroup,
  SidebarHeader,
  SidebarItem,
  SidebarProvider,
  SidebarTrigger,
} from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

用 `SidebarProvider` 包住 `Sidebar` 與 `SidebarTrigger`，它負責共用抽屜的開關狀態。螢幕寬度 960px 以上時，側邊欄固定在版面中（寬 240px、滿高、sticky）；低於 960px 則隱藏，由 `SidebarTrigger` 在 `Drawer` 裡開啟同一份內容。側邊欄預設是 `h-dvh`；傳入 `h-full` 之類的 `className` 就能配合容器高度，範例即是如此。

```tsx
import {
  Sidebar,
  SidebarBody,
  SidebarGroup,
  SidebarHeader,
  SidebarItem,
  SidebarProvider,
  SidebarTrigger,
} from '@weichenlin/swell-ui'

export function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <div className="flex">
        <Sidebar aria-label="Primary">
          <SidebarHeader>Acme</SidebarHeader>
          <SidebarBody>
            <SidebarGroup label="Workspace">
              <SidebarItem href="/" aria-current="page">
                Overview
              </SidebarItem>
            </SidebarGroup>
          </SidebarBody>
        </Sidebar>
        <main>
          <SidebarTrigger />
          {children}
        </main>
      </div>
    </SidebarProvider>
  )
}
```

搭配 router 時，用 `<SidebarItem asChild><Link href="/">Overview</Link></SidebarItem>`；連結會自行設定 `href` 與 `aria-current="page"`。

## API

### SidebarProvider

保存抽屜的開關狀態。只接受 `children`。

### Sidebar

另外接受 `nav` 的 props。`aria-label` 與 `aria-labelledby` 擇一傳入；型別會要求這點。

<AutoTypeTable path="src/components/sidebar/sidebar.tsx" name="SidebarProps" />

### SidebarTrigger

開啟抽屜的選單按鈕；只在 960px 以下顯示。另外接受 `button` 的 props，但不含 `children`、`type`、`aria-expanded` 與 `aria-controls`，這些由元件自己設定。

<AutoTypeTable path="src/components/sidebar/sidebar.tsx" name="SidebarTriggerProps" />

### SidebarItem

適用一般 `a` 的 props。用 `aria-current="page"` 標示目前所在的項目。在抽屜裡，連結自己處理的點擊（`preventDefault`）會關閉抽屜；帶修飾鍵的點擊會開新分頁，抽屜保持開啟。

### 其他部件

都接受各自元素的標準 props。

| 部件            | 說明                                                |
| --------------- | --------------------------------------------------- |
| `SidebarHeader` | 固定在主體上方的品牌列；在抽屜裡包含關閉按鈕。      |
| `SidebarBody`   | 放群組的區域；唯一會捲動的部分。                    |
| `SidebarFooter` | 固定在主體下方。                                    |
| `SidebarIcon`   | 項目前方 16px 的裝飾性圖示。                        |
| `SidebarBadge`  | 項目尾端的數量，是小型 `Badge`；接受 `BadgeProps`。 |

## 無障礙

- 固定的側邊欄與抽屜都會渲染 `nav` landmark，需要名稱，所以 `aria-label` 或 `aria-labelledby` 必填。抽屜沿用同一個名稱。
- DOM 裡同一時間只有一份內容：抽屜關閉時不會渲染任何東西。
- 群組是清單，會朗讀項目數量；群組的 `label` 是清單的名稱。
- 項目是連結：目前所在的項目請設 `aria-current="page"`。router 的 `Link` 會自動設定。
- `SidebarIcon` 是 `aria-hidden`。`SidebarBadge` 是項目名稱的一部分，前面有空格（「Projects 8」）。
- 抽屜是 modal：焦點移入並留在裡面，按 Esc、關閉按鈕（`Close navigation`）或點擊背景都會關閉，並把焦點還給觸發按鈕。
- 視窗放寬到 960px 以上時，開啟中的抽屜會自動關閉。
- 強制色彩模式下，目前項目使用 `Highlight` 與 `HighlightText`。
