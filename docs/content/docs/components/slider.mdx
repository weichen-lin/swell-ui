## Installation

```tsx
import { RangeSlider, Slider } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { RangeSlider, Slider } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <>
      <Slider label="Volume" defaultValue={40} />
      <RangeSlider
        label="Price range"
        thumbLabels={['Minimum price', 'Maximum price']}
        defaultValue={[200, 800]}
        min={0}
        max={1000}
        step={50}
      />
    </>
  )
}
```

Every slider needs a visible `label`, or an `aria-label` when the surrounding context already names it.

## API

### Slider

Own props only; every other `<div>` attribute passes through to the root, except `onChange`, `children` and `role`. `className` and `ref` target the root `div`.

<AutoTypeTable path="src/components/slider/types.ts" name="SliderProps" keep={['className']} />

`label` and `aria-label` are alternatives: pass a visible `label`, or only `aria-label`. `value` and `defaultValue` are alternatives: pass one, not both. `defaultValue` is `min` when omitted.

`SliderChangeDetails` is `{ thumbIndex: 0 | 1; reason: 'pointer' | 'keyboard' | 'input' | 'cancel' }`. `SliderCommitDetails` is the same without the `cancel` reason.

### RangeSlider

Takes the same props as `Slider`, except these, which replace their `Slider` counterparts. `defaultValue` is `[min, max]` when omitted.

Holding a key previews every step through `onValueChange`; `onValueCommit` runs once on release, or when focus leaves, and never for a gesture that ends where it began. Keys with Ctrl, Alt, Meta or Shift held are ignored. A thumb stops at its neighbour and never swaps or pushes it, so Home and End respect `minStepsBetweenThumbs`.

## Accessibility

- Each thumb is a native `<input type="range">` inside a `role="group"`, so the browser provides the slider role, value and form submission.
- The visible `label` names the group and each thumb. In a `RangeSlider`, each thumb is named by the label plus its `thumbLabels` entry; with only `aria-label`, by `aria-label` plus the thumb label.
- The spoken value is `formatValue(value)`, or `getValueText` when you pass it. The visible value, the bounds and the marks are `aria-hidden`.
- Helper and error text are linked with `aria-describedby`; the error also sets `aria-invalid`.
- Pointer cancel, a lost capture or a window blur rolls the value back, through `onValueChange` with reason `cancel`, without committing.
- Esc is not handled, so it reaches outer handlers such as a dialog.
- The hit area is 44px tall, and the thumb is 18px with a 44px target around it.
- Native form reset restores uncontrolled defaults; a controlled reset is the owner's choice.
- In forced colors mode the track, range and thumb use `CanvasText`, `Highlight` and `ButtonText`, and disabled uses `GrayText`.
- `min` and `max` must be finite with `min < max`; values must be on the step grid, ordered, and satisfy the thumb gap, or the slider throws.
