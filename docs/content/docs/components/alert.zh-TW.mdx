## 安裝

```tsx
import { Alert } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Alert } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Alert tone="info" title="Next sync at 11:00">
      The order count refreshes after the sync completes.
    </Alert>
  )
}
```

## 無障礙

- 警示訊息沒有 role，也不是 live region：它不會自己朗讀。需要朗讀的更新，請把訊息放進 live region。
- 圖示是 `aria-hidden`。不要只靠 tone 傳達意思：請寫在標題或文字裡。
- 關閉按鈕的名稱是 `Dismiss alert`；傳 `dismissLabel` 即可在地化。
- 顯示與否由呼叫端控制：`onDismiss` 只回報點擊。
- 長字會換行，所以窄容器不會溢出。
- 強制色彩模式下，邊框用 `CanvasText` 繪製。
