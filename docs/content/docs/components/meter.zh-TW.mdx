## 安裝

```tsx
import { Meter } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Meter } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Meter
      label="Health"
      summary="9 of 13 report health"
      segments={[
        { label: 'Healthy', value: 9, tone: 'success' },
        { label: 'No health', value: 4, tone: 'neutral' },
      ]}
    />
  )
}
```

## 鍵盤操作

Meter 不是互動元件，不會取得焦點，所以沒有鍵盤操作。

## 無障礙

- 比例條是裝飾（`aria-hidden`）。圖例是以 `label` 命名的清單，每個值與標籤是一個清單項目，所以沒有任何資訊只靠顏色傳達。
- Meter 不是 `role="meter"` 或 `progressbar`，也沒有最小值與最大值。它描述的是比例分布，不是朝目標前進的進度。
- 區段的 `label` 同時作為 React key，所以必須唯一。
- `summary` 是標籤列上的純文字；把使用者最在意的數字放在這裡。

## 主題

`themes/flat.css` 不會改變 Meter：它沒有用到陰影，也沒有用到主題的圓角。
