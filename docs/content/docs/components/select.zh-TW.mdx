## 安裝

```tsx
import { Select } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Select } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Select
      label="Region"
      placeholder="Choose a region"
      options={[
        { value: 'us-east', label: 'US East' },
        { value: 'eu-west', label: 'EU West' },
      ]}
    />
  )
}
```

`Select` 渲染的是真正的 `<select>`，所以原生的鍵盤操作、typeahead、表單、驗證與自動填入都能運作。瀏覽器支援 `appearance: base-select` 時，選單會套上對應的樣式；不支援時維持原生外觀。它與 `Input` 共用同一個外框。

## 無障礙

- 它是原生的 `<select>`：角色、值、typeahead 與表單行為都由瀏覽器提供。
- 可見的 `label` 是這個 select 真正的 `<label>`。只有 `aria-label` 時就沒有 label 元素；型別要求二選一，而 `floating` 必須搭配可見的 `label`。
- `helperText` 與 `error` 透過 `aria-describedby` 連結；錯誤時還會設定 `aria-invalid`，並顯示 `aria-hidden` 的圖示。
- 「尚未選擇」的空選項是隱藏且停用的，不會出現在清單裡；`required` 的 select 在選好真正的選項前，驗證都不會通過。
- 選項圖示、`start` 與箭頭都是 `aria-hidden`。圖示不加文字，所以無障礙名稱與 typeahead 只看 `label`。
- `form.reset()` 會還原成初始選項，觸發區的圖示也會跟著還原。
- 樣式化的選單只套用在精細指標（fine pointer）；觸控裝置保留系統選單，文字放大到 16px，點擊範圍至少 44px。
- 強制色彩模式下，停用的邊框用 `GrayText`，聚焦以外框繪製。
- 選單以短暫的淡入呈現，開啟 `prefers-reduced-motion: reduce` 時不播放。
