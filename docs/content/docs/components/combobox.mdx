## Installation

```tsx
import { Combobox } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Combobox } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Combobox
      label="Project"
      placeholder="Search projects"
      options={[
        { value: 'payment-api', label: 'Payment API' },
        { value: 'analytics', label: 'Analytics' },
      ]}
    />
  )
}
```

Selection is by option `value`, a stable ID, never by the typed text. Use `value` with `onValueChange` for controlled state, or `defaultValue` for uncontrolled state. With `name`, the form submits the `value`.

## Accessibility

- It follows the combobox pattern with a list: the input has `role="combobox"`, `aria-autocomplete="list"`, `aria-expanded` and `aria-controls`. DOM focus never leaves the input; options are addressed with `aria-activedescendant`.
- The listbox is named by `label` or `aria-label`; groups are named by their `label`. Options use `aria-selected` and `aria-disabled`, and an option `description` is its accessible description.
- The result count is announced politely and so are `loadingText` and a string `searchError`; localize the count with `getResultsText`. The empty message is a status, never an option.
- The clear and chevron buttons have accessible names (`clearLabel`, `openLabel`, `closeLabel`); the chevron is out of the Tab order, since the input already opens the list.
- `required` checks for a selection, not just typed text. The message is `requiredText` or, when `value` matches no option, `unresolvedText`; supply `selectedOption` when the selected ID may be missing from the current results.
- Option icons, `start` and the check mark are `aria-hidden`.
- Typing with an IME is safe: Enter that completes a composition is not intercepted, and the finished text is searched.
- On touch screens options and buttons get at least 44px. In forced colors mode the active option is outlined in `Highlight`.
- The panel fade is skipped under `prefers-reduced-motion: reduce`.
