## 安裝

```tsx
import { toast, Toaster } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

在 app 根部附近掛載一個 `<Toaster />`；如果 `action` 會渲染 `<Link>`，要掛在 router 裡面。之後可以在任何地方呼叫 `toast`：事件處理函式、mutation、loader。每次呼叫都會回傳該通知的 id。

```tsx
import { Toaster } from '@weichenlin/swell-ui'

export function App({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <Toaster />
    </>
  )
}
```

```tsx
import { toast } from '@weichenlin/swell-ui'

toast({ title: 'Changes saved', description: 'Your settings are up to date.' })
toast.success('Synced')
```

## API

### toast

`toast(options)` 會顯示一則通知並回傳它的 id。用畫面上仍存在的通知 id 呼叫時，會就地取代該通知；沒有傳的欄位會回到預設值。

```ts
toast(options: ToastOptions): string
```

`action` 是帶有 `label` 的物件時，會渲染成小型 secondary 按鈕。其他節點則原樣渲染，且不會自己關閉通知。

### 輔助函式

```ts
toast.success(title: ReactNode, options?: Omit<ToastOptions, 'title' | 'type'>): string
toast.info(title: ReactNode, options?: Omit<ToastOptions, 'title' | 'type'>): string
toast.warning(title: ReactNode, options?: Omit<ToastOptions, 'title' | 'type'>): string
toast.error(title: ReactNode, options?: Omit<ToastOptions, 'title' | 'type'>): string
toast.loading(title: ReactNode, options?: Omit<ToastOptions, 'title' | 'type'>): string
toast.update(id: string, patch: ToastPatch): void
toast.dismiss(id?: string): void
toast.promise<T>(promise: Promise<T> | (() => Promise<T>), steps: ToastPromiseOptions<T>): string
```

| 函式            | 說明                                                         |
| --------------- | ------------------------------------------------------------ |
| `toast.success` | 成功通知。                                                   |
| `toast.info`    | 資訊通知。                                                   |
| `toast.warning` | 警告通知。                                                   |
| `toast.error`   | 以 `danger` 類型顯示，會一直顯示到被關閉。                   |
| `toast.loading` | 轉圈圖示；會一直顯示到被更新或關閉。                         |
| `toast.update`  | 合併到仍在畫面上的通知並重新計時。id 不存在時不做任何事。    |
| `toast.dismiss` | 播放一則通知的退場動畫；不傳 id 則是全部通知。               |
| `toast.promise` | 載入中的通知，promise 完成後就地變成成功或 danger。回傳 id。 |

`ToastPatch` 是 `Partial<ToastOptions>` 去掉 `id` 與 `toasterId`：通知會一直留在建立它的 Toaster。

### toast.promise

接收一個 promise（或回傳 promise 的函式），以及每種結果的步驟。步驟可以是標題，或不含 `id` 與 `type` 的完整選項；`success` 與 `error` 也可以是以結果或錯誤為參數的函式。每個步驟都會取代前一個步驟的欄位，所以載入中的描述或 action 不會殘留。如果使用者在 promise 完成前就關掉通知，它會維持關閉。

## 無障礙

- 兩個 live region 一開始就存在，公告才能正常運作：大部分通知用 `role="status"`（polite），`danger` 用 `role="alert"`（assertive）。同一個畫格內出現的通知會一起朗讀，相同的文字也會再朗讀一次。
- 通知出現時會被朗讀。更新時只朗讀新的狀態。
- 每張卡片以標題為名稱、描述為說明，並可透過 F6 聚焦，整段文字會被朗讀。
- 滑鼠移入、鍵盤聚焦與分頁隱藏都會暫停計時器，所以閱讀期間通知不會消失；剩餘時間會保留，只有更新才會重設。`danger` 與 `loading` 不會自己消失。
- 圖示是 `aria-hidden`；意思由文字傳達。開啟 `prefers-reduced-motion: reduce` 時，載入圖示改為虛線圓環。
- `dismissible: false` 時沒有關閉按鈕，也不能滑動或按 Esc：通知只會因計時結束或 `toast.dismiss()` 離開。
- 滑動方向是堆疊所在的邊緣，角落位置再加上靠側的那一邊。選取文字不算滑動，按鈕與連結保有自己的點擊。
- 有強制回應的對話框開啟時，堆疊會移進對話框裡，通知才看得到、點得到；對話框關閉後再移回來。
- 寬度 600px 以下時，卡片滿版並各留 16px 邊距，最多同時顯示 2 則。
- viewport 的標籤是 `Notifications (F6)`，關閉按鈕是 `Close`，兩者都是英文。
- 強制色彩模式下，卡片邊框用 `CanvasText` 繪製。
- 伺服器端不會渲染任何東西：通知只在客戶端呼叫之後才存在。
