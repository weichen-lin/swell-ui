## 安裝

```tsx
import { Table, type TableColumn } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

`Table` 是受控的 UI：搜尋、排序、選取與分頁只負責顯示控制項並回報變更。你要自己提供已經過濾、排序、切頁的 `data`。

```tsx
import { Table, type TableColumn } from '@weichenlin/swell-ui'

type Invoice = { id: string; customer: string; amount: number }

const columns: TableColumn<Invoice>[] = [
  { id: 'id', header: 'Invoice', cell: (row) => row.id, rowHeader: true },
  { id: 'customer', header: 'Customer', cell: (row) => row.customer },
  { id: 'amount', header: 'Amount', cell: (row) => `$${row.amount}`, numeric: true },
]

export function Example({ invoices }: { invoices: Invoice[] }) {
  return <Table data={invoices} columns={columns} getRowId={(row) => row.id} title="Invoices" />
}
```

## 無障礙

- 標題儲存格是 `scope="col"`；`rowHeader` 欄位會渲染成 `<th scope="row">`。
- 已排序的標題會帶 `aria-sort`，排序控制項是標題內真正的按鈕。
- 表格的名稱來自 `title`，或你設定的 `aria-label`、`aria-labelledby`。捲動區域是有名稱的 `section`（預設為 `Table`），並設 `tabindex="0"`，鍵盤使用者才能捲動過寬的表格。
- 資料列核取方塊的名稱是 `Select row <id>`；全選核取方塊的名稱是 `Select all rows on this page`。
- 已選取數量與分頁範圍是 `<output>` 元素，變動時會被朗讀。
- 分頁按鈕用 `aria-disabled` 而非原生 `disabled`，所以在首頁、末頁時焦點不會消失。
- 所有內建文字都能透過 `labels` 替換，方便在地化。
- 由右至左的版面中，分頁的箭頭會翻轉。
