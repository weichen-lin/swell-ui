## 安裝

```tsx
import { Card, CardContent, CardHeader } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

Card 本身沒有內距，由 `CardHeader` 與 `CardContent` 提供，所以清單與表格可以貼齊卡片邊緣。

```tsx
import { Card, CardContent, CardHeader } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Card as="section">
      <CardHeader title="Resources" description="Managed in shop-prod" />
      <CardContent>Any content goes here.</CardContent>
    </Card>
  )
}
```

## 鍵盤操作

卡片不可聚焦，也不接收按鍵。放在裡面的控制項（例如 `action` 連結）沿用各自的按鍵。

## 無障礙

- 使用 `as="section"` 或 `as="article"` 時，卡片是以 `CardHeader` 標題命名的區塊。
- 卡片上明確設定的 `aria-label` 優先於標題。
- `div` 卡片不會被命名，沒有標題列的卡片也不會設定 `aria-labelledby`。
- 標題是 heading 元素：預設 `h2`，傳 `headingLevel={3}` 則是 `h3`。請依頁面大綱選擇層級。
