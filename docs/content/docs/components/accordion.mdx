## Installation

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Accordion defaultValue="project">
      <AccordionItem value="project">
        <AccordionTrigger>Project</AccordionTrigger>
        <AccordionContent>Project settings</AccordionContent>
      </AccordionItem>
      <AccordionItem value="members">
        <AccordionTrigger>Members</AccordionTrigger>
        <AccordionContent>Member settings</AccordionContent>
      </AccordionItem>
    </Accordion>
  )
}
```

Item values must be unique and non-empty. Each trigger renders its own heading, so its content must not hold interactive elements. In single mode the value is a `string | null`; with `type="multiple"` it is a `readonly string[]`. Use `value` with `onValueChange` for controlled state, or `defaultValue` for uncontrolled state. The type cannot change while mounted: give the component a new `key` to switch.

## Accessibility

- Each trigger is a native `<button>` inside a heading of level `headingLevel` (3 by default): pick the level that fits your page outline.
- A trigger has `aria-expanded` and `aria-controls`. Its name is the title only; `description` is announced as the description.
- The content is not a landmark by default. Set `region` to name it after its trigger when it holds complex content, and use it sparingly.
- Closed content is `inert` and hidden from assistive technology at once, so focus never lands in it. If focus was inside when it closed, it moves to the item's trigger, then to a neighbouring enabled trigger.
- `disabled` turns off triggers only: fields inside the content stay usable, and `keepMounted` (the default) keeps their values and form data while the item is closed.
- Arrow keys, Home and End ignore combinations with Ctrl, Alt, Meta or Shift, and a nested accordion handles its own keys and selection.
- The chevron is `aria-hidden`. In forced colors mode a disabled trigger is `GrayText`.
- The height animation runs 200ms to open and 160ms to close; with `prefers-reduced-motion: reduce` it switches immediately.
