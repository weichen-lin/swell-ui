## 安裝

```tsx
import { Radio, RadioGroup } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Radio, RadioGroup, RadioGroupItems, RadioGroupLabel } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <RadioGroup name="plan" defaultValue="pro">
      <RadioGroupLabel>Plan</RadioGroupLabel>
      <RadioGroupItems>
        <Radio value="free" label="Free" />
        <Radio value="pro" label="Pro" />
      </RadioGroupItems>
    </RadioGroup>
  )
}
```

`Radio` 必須放在 `RadioGroup` 裡。除非傳入 `defaultValue` 或 `value`，或使用者自己選了一項，否則不會有選取項。

## 組成

群組負責串接各部件的關聯，你決定每個部件放在哪裡，也可以不放。

```tsx
<RadioGroup name="plan" invalid={Boolean(error)}>
  <RadioGroupLabel>Plan</RadioGroupLabel>
  <RadioGroupDescription>Pick one.</RadioGroupDescription>
  <RadioGroupItems>
    <Radio value="free" label="Free" />
    <Radio value="pro" label="Pro" />
  </RadioGroupItems>
  {error && <RadioGroupError>{error}</RadioGroupError>}
</RadioGroup>
```

| 部件                    | 用途                                                                                                         |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| `RadioGroupLabel`       | 群組的名稱，必填時會附上星號。                                                                               |
| `RadioGroupDescription` | 較淡的提示文字，以 `aria-describedby` 連結。                                                                 |
| `RadioGroupItems`       | radio 的預設排版，依 `orientation` 決定方向；也可以換成任何元素。                                            |
| `RadioGroupError`       | 群組層級的訊息，以 `aria-describedby` 連結。可傳入 `icon`，設為 `false` 或 `null` 則隱藏；只在需要時才渲染。 |

### 隱藏標籤

標籤就是一般元素，樣式可以自由調整。加上 `sr-only` 就只保留給輔助技術：

```tsx
<RadioGroup name="plan">
  <RadioGroupLabel className="sr-only">Plan</RadioGroupLabel>
  <RadioGroupItems>{/* radios */}</RadioGroupItems>
</RadioGroup>
```

沒有標籤部件時，請改用 `aria-label` 或 `aria-labelledby` 為群組命名。

## 無障礙

- 群組是帶 `role="radiogroup"` 的 `<fieldset>`，透過 `aria-labelledby` 以 `RadioGroupLabel` 為名稱；沒有標籤部件時則用 `aria-label`。每個 radio 都是原生 `<input type="radio">`，以自己的標籤為名稱。
- `RadioGroupDescription` 與 `RadioGroupError` 只在有渲染時，才會用 `aria-describedby` 連結到群組與每個 radio；錯誤圖示是 `aria-hidden`。
- `invalid` 會在群組上設定 `aria-invalid`，`required` 會設定 `aria-required`。原生驗證會要求選一項，不需要自訂的送出處理函式。
- 選取的值會放在群組的 `name` 下送出。原生表單重設會還原非受控的預設值，且不會呼叫 `onValueChange`。
- `Radio` 放在 `RadioGroup` 之外會丟出錯誤，且值必須唯一、不能是空字串。
- 在觸控螢幕上，每一列至少 44px 高，相鄰的點擊範圍不會重疊。
- 強制色彩模式下，radio 使用 `Canvas` 與 `Highlight`，停用則用 `GrayText`。
