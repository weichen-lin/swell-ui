## 安裝

```tsx
import { Radio, RadioGroup } from '@weichenlin/swell-ui'
```

CSS 包含在 `styles.css` 裡，在 Tailwind 之後引入一次即可（見[安裝](/installation)）：

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## 用法

```tsx
import { Radio, RadioGroup } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <RadioGroup name="plan" legend="Plan" defaultValue="pro">
      <Radio value="free" label="Free" />
      <Radio value="pro" label="Pro" />
    </RadioGroup>
  )
}
```

`Radio` 必須放在 `RadioGroup` 裡。除非傳入 `defaultValue` 或 `value`，或使用者自己選了一項，否則不會有選取項。

## API

### RadioGroup

只列元件自己的 props；其他 `<fieldset>` 屬性都會直接傳給元素，`onChange` 除外。`className` 會套在 fieldset 上。

只列元件自己的 props；其他 `<input>` 屬性都會直接傳給元素。`name`、`checked`、`required`、`form` 與 `aria-invalid` 由群組管理。

## 無障礙

- 群組是帶 `role="radiogroup"` 的 `<fieldset>`，透過 `aria-labelledby` 以 `<legend>` 為名稱。每個 radio 都是原生 `<input type="radio">`，以自己的標籤為名稱。
- 群組的 `description` 與錯誤，除了連結到群組，也用 `aria-describedby` 連結到每個 radio；錯誤圖示是 `aria-hidden`。
- `error` 會在群組上設定 `aria-invalid`，`required` 會設定 `aria-required`。原生驗證會要求選一項，不需要自訂的送出處理函式。
- 選取的值會放在群組的 `name` 下送出。原生表單重設會還原非受控的預設值，且不會呼叫 `onValueChange`。
- `Radio` 放在 `RadioGroup` 之外會丟出錯誤，且值必須唯一、不能是空字串。
- 在觸控螢幕上，每一列至少 44px 高，相鄰的點擊範圍不會重疊。
- 強制色彩模式下，radio 使用 `Canvas` 與 `Highlight`，停用則用 `GrayText`。
