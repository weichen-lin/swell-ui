## Installation

```tsx
import { Meter } from '@weichenlin/swell-ui'
```

The CSS comes with `styles.css`, imported once after Tailwind (see [Installation](/installation)):

```css
@import 'tailwindcss';
@import '@weichenlin/swell-ui/styles.css';
```

## Usage

```tsx
import { Meter } from '@weichenlin/swell-ui'

export function Example() {
  return (
    <Meter
      label="Health"
      summary="9 of 13 report health"
      segments={[
        { label: 'Healthy', value: 9, tone: 'success' },
        { label: 'No health', value: 4, tone: 'neutral' },
      ]}
    />
  )
}
```

## Keyboard

Meter is not interactive and takes no focus, so it has no keyboard behavior.

## Accessibility

- The bar is decorative (`aria-hidden`). The legend is a list named by `label`, with each value and label as a list item, so nothing is conveyed by color alone.
- Meter is not a `role="meter"` or `progressbar` and has no minimum or maximum. It describes a split, not progress toward a goal.
- Segment `label` doubles as the React key, so it must be unique.
- `summary` is plain text on the label row; put the figure people care about there.
